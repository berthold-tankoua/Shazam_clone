🚀 Shazam Recognition Web App

n8n + Laravel + HTML/CSS + AI

A web application prototype that combines automation, artificial intelligence, and a modern web stack to recognize music from audio samples.
This project demonstrates how workflow automation, backend frameworks, and AI services can work together in a practical real-world use case.

📌 Overview

This project integrates:

n8n → automation workflows, webhooks, API orchestration

Laravel → backend logic, routing, API handling

HTML / CSS frontend → simple responsive user interface

AI audio processing → music recognition or audio analysis

Goal: build a lightweight music-recognition web app inspired by modern AI automation workflows.

⚙️ Features

✅ Audio upload or recording interface
✅ Automated workflow processing (n8n)
✅ Backend API handling with Laravel
✅ AI-based audio recognition or suggestion
✅ Responsive UI (desktop / tablet / mobile)
✅ Scalable architecture for future SaaS projects
